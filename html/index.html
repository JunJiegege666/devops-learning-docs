开始学习 (Linux)
GitHub 仓库

第一阶段：Linux 基础

用户管理、权限控制、Systemd 服务配置、Nginx 反向代理与 Shell 脚本自动化监控。

第二阶段：Docker 容器化

Dockerfile 编写、Docker Compose 服务编排、Portainer 可视化管理与微服务架构。

第三阶段：CI/CD 自动化

第四阶段：VitePress 文档站自动化部署

从零搭建一个基于 VitePress 的技术文档网站，并实现 "本地写作 -> Git 推送 -> 自动构建 -> 服务器更新" 的全自动化流程。
